# # 🚀 Atividades — Integração Contínua e DevOps

Repositório destinado ao armazenamento das atividades, exercícios e projetos desenvolvidos durante as aulas da disciplina de **Integração Contínua e DevOps**.

## 📚 Sobre a disciplina

Durante a disciplina, são estudados conceitos, ferramentas e práticas relacionadas ao desenvolvimento e à entrega contínua de software.

O objetivo é compreender como integrar práticas de desenvolvimento, testes, versionamento e infraestrutura para tornar o processo de desenvolvimento de sistemas mais rápido, organizado, automatizado e confiável.

## 🎯 Objetivos

- 🧩 Compreender os conceitos fundamentais de **DevOps**;
- 🔄 Entender o funcionamento da **Integração Contínua (CI)**;
- 🚀 Conhecer conceitos de **Entrega e Implantação Contínua (CD)**;
- 🌿 Utilizar ferramentas de **controle de versão**, como Git e GitHub;
- ⚙️ Conhecer ferramentas de automação e integração;
- 🧪 Compreender a importância da automação de testes;
- 📦 Trabalhar com processos de build, integração e deploy;
- 🤝 Entender a colaboração entre equipes de desenvolvimento e operações.
