# 📝 Atividade — Aula 01

## 📋 Orientações da Atividade

1. **Formação dos grupos:**  
   Formem grupos de **3 a 5 integrantes**.  
   > ⚠️ Importante: As atividades semanais deverão ser desenvolvidas e entregues em grupo, utilizando essa mesma composição.

2. **Reunião semanal:**  
   Após a definição dos integrantes, o grupo deverá reunir-se semanalmente para realizar as atividades propostas em aula.

3. **Criação do repositório:**  
   Criem um repositório no **GitHub**, que servirá como diretório principal das atividades da disciplina durante todo o semestre.

   No repositório, deverá ser criado um arquivo **Markdown (`.md`)** contendo um resumo da **Aula 01**, abordando os principais conceitos discutidos.

   🔗 **Repositório:** [Atividades DevOps](https://github.com/rafamans4no/AtividadesDevOps)
