# 📝 Atividade — Aula 05

## 📋 Orientações da Atividade

Escolham 3 Actions disponíveis no GitHub Marketplace e desenvolvam um projeto que utilize essas ferramentas em uma pipeline automatizada, aplicando cada Action em uma etapa adequada do processo. Configurem o workflow no GitHub Actions, executem a pipeline e verifiquem o funcionamento de cada etapa, documentando no projeto quais Actions foram utilizadas, suas respectivas funções e como contribuíram para a automação do processo.
